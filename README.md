# Система учета временных отсутствий
Контекст проекта
Компания фиксировала кратковременные отсутствия сотрудников вручную. Данные терялись, руководители согласовывали устно, кадровые документы заполнялись с опозданием или не заполнялись вовсе.

Моя роль
Бизнес-аналитик. Описала процесс как есть, выявила разрывы, спроектировала целевой процесс с нуля.

Что сделала
Разработала систему учёта временных отсутствий на базе корпоративного портала и Битрикс24. Спроектировала два типа заявок (УРВ-2 до 3 часов, УРВ-4 до 8 часов) с разной логикой согласования, BPMN-схему с четырьмя участниками процесса, статусную модель из 10 состояний и UI-макеты для сотрудника и руководителя.
